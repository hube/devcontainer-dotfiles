# Worktree Guidance Design

Status: Approved for implementation

## Scope

This change makes the shared devcontainer Git ignore configuration compatible
with the mandatory worktree workflow and tightens the workspace-level agent
instructions that govern that workflow.

The tracked change belongs to `devcontainer-dotfiles`. The workspace-level
`/workspaces/agent-devcontainer/CLAUDE.md` has no enclosing Git repository and
is updated directly, outside the pull request.

## Shared ignore rule

Decided (owner, 2026-07-14, in session): append a hand-maintained section to
`home/.gitignore`, after the generated `gibo` content. Its comment will explain
that the section is not generated by `gibo` and that `.worktrees/` ignores
agent-created linked worktrees in every devcontainer.

Use the unanchored directory pattern `.worktrees/`. Git applies it to matching
directories at any depth, so `**/.worktrees/` adds no useful behavior.

## Agent guidance

Decided (owner, 2026-07-14, in session): update the workspace-level
`CLAUDE.md` directly with these rules:

- Treat tests, builds, installers, formatters, generators, and dependency
  commands as mutating unless their non-mutating behavior is verified.
- Run repository and worktree checks in the repository containing the target
  file.
- Permit bypass only when a higher-priority instruction explicitly requires
  it, with the exception and risk stated before changes begin.
- Assign post-merge worktree removal to the agent responsible for integration
  or cleanup.
- Before editing, record the absolute repository and worktree paths, branch,
  and linked-worktree verification result.
- Restate the complete worktree mandate in every subagent dispatch, including
  the prohibition on direct and indirect primary-checkout mutations.
- Do not infer an exception from urgency, triviality, documentation-only work,
  a minor fix, or a request to produce an uncommitted patch.
- If `.worktrees` is not ignored, stop and report incomplete environment setup
  rather than editing `.gitignore` in the primary checkout.
